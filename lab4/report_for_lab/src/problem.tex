\CWHeader{Лабораторная работа \textnumero 4}

\CWProblem{
Требуется разработать программу для поиска заданной последовательности слов (паттерна) в тексте, представленном в виде последовательности слов, прочитанном из стандартного потока ввода с учетом информации о строках и позициях.

\vspace{1em}
{\bfseries Вариант алгоритма:} Алгоритм поиска подстроки Кнута-Морриса-Пратта (KMP с использованием Z-algorithm).

{\bfseries Входные данные:} { \normalfont\ttfamily Первая строка содержит паттерн (последовательность слов до 16 символов); последующие строки содержат текст для поиска. }

{\bfseries Выходные данные:} { \normalfont\ttfamily Для каждого вхождения паттерна выводится номер строки и позиция первого слова паттерна на этой строке в формате \enquote{строка, позиция}. }
}
