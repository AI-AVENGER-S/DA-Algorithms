\CWHeader{Лабораторная работа \textnumero 5}

\CWProblem{
Требуется разработать программу для определения лексикографически минимальной циклической ротации заданной строки, используя суффиксное дерево.

\vspace{1em}
{\bfseries Вариант алгоритма:} Суффиксное дерево (Suffix Tree) с оптимальным поиском минимальной ротации через обход дерева.

{\bfseries Входные данные:} { \normalfont\ttfamily Одна строка, содержащая исходную последовательность символов. }

{\bfseries Выходные данные:} { \normalfont\ttfamily Лексикографически минимальная циклическая ротация исходной строки длиной, равной длине входной строки. }
}
